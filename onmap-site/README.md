# balakovo-go.ru

Самостоятельный статический сайт на Next.js. Главная страница находится по `/`, раздел OnMap — по `/onmap/`. Проект не зависит от пакетов и исходников мобильного приложения или backend.

## Локальная работа

```sh
cd onmap-site
npm ci
npm run dev
```

Проверки и сборка:

```sh
npm run lint
npm run typecheck
npm run build
```

Next.js экспортирует готовые файлы в `out/`. Для обычного статического хостинга разместите **содержимое** `out/` в корне сайта. Динамический сервер и API маршруты этому сайту не нужны. Папки страниц содержат `index.html`; `out/404.html` — общая страница ошибки. Адрес `/onmap/404/` содержит вариант ошибки для раздела OnMap.

## Ссылки на приложения

Задаются перед сборкой через `.env.local` или переменные окружения:

- `NEXT_PUBLIC_ANDROID_APK_URL`
- `NEXT_PUBLIC_APP_STORE_URL`

Образец — `.env.example`. Если переменная не задана или не содержит URL с `http:`/`https:`, сайт показывает «Скоро». Для изменения ссылок нужно пересобрать статические файлы.

Сведения, требующие подтверждения перед публикацией, собраны в `docs/ONMAP_SITE_CONTENT_TODO_RU.md`.
