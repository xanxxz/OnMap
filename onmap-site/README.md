# balakovo-go.ru

Самостоятельный статический сайт на Next.js. Главная страница находится по `/`, OnMap — по `/onmap/`, авторская страница — по `/sssvam/`. На главной есть компактное пустое состояние опросов; функция опросов не подключена. Проект не зависит от пакетов и исходников мобильного приложения или backend.

## Локальная работа

```sh
npm ci
npm run dev
```

Проверки и сборка:

```sh
npm run lint
npm run typecheck
npm run build
```

Next.js экспортирует готовые файлы в `out/`. Для обычного статического хостинга разместите **содержимое** `out/` в корне сайта. Динамический сервер и API маршруты этому сайту не нужны. Папки страниц содержат `index.html`; `out/404.html` — общая страница ошибки. Адрес `/onmap/404/` содержит вариант ошибки для раздела OnMap.

Режим разработки хранит файлы в `.next-dev/`, а production-сборка — в `.next/`. Так команды `npm run dev` и `npm run build` не перезаписывают файлы друг друга.

## OnMap Android APK

Релизный APK хранится в проекте по пути `public/onmap/downloads/onmap-android.apk` и раздаётся Next.js по адресу `/onmap/downloads/onmap-android.apk`. Положите новый проверенный APK по этому пути перед развёртыванием сайта. Файл около 123 МБ исключён из Git: он слишком велик для обычного исходного коммита и должен передаваться через хостинг/релизное хранилище отдельно. Не переименовывайте его без одновременного обновления ссылки на странице.

При обычном запуске Next.js папка `public/` обслуживается приложением напрямую. Если используется временный статический экспорт, Next.js копирует этот же файл в `out/onmap/downloads/`; загружать нужно содержимое `out/` в корень сайта. APK в `out/` является производной копией, исходный локальный экземпляр находится в `public/`.

SHA-256 текущего APK и сведения о проверке подписи опубликованы на `/onmap/download/`. После замены APK обязательно обновите на этой странице версию, build number и SHA-256.

Текущий локальный релиз: OnMap Android `1.0` (`versionCode 1`), размер `128889633` байта. SHA-256 APK: `dac1e85999197f43f46a81e43479e423c441266306841e53a656aae697fb03b1`. Подпись проверена `apksigner`; отпечаток сертификата SHA-256: `4991d9e9aac77e30cdf764eded2e0a19ac0297a71f304a50681b28274e254a0c`.

Ссылка App Store задаётся через `NEXT_PUBLIC_APP_STORE_URL` в `.env.local` или переменных окружения. Образец — `.env.example`; без валидной HTTPS/HTTP ссылки сайт показывает, что App Store пока недоступен. Для изменения этой ссылки требуется новая сборка сайта.

Факты, использованные в публичных текстах, собраны в `docs/ONMAP_SITE_FACTS_RU.md`. Логотипы, палитра и происхождение изображений описаны в `docs/BRAND_SYSTEM_RU.md`.
