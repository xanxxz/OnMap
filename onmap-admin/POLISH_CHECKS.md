# Доводка деталей локальной админки — 28 октября 2026

Утверждённая композиция сохранена. Этот проход меняет только `onmap-admin/`.
Backend, VPS, БД, production, API-контракты, авторизация и хранение токена не менялись.
Коммит и деплой не выполнялись, зависимости не добавлялись.

## Общие компоненты

- Единые состояния hover / active / focus-visible / disabled / busy / error, фирменный видимый фокус, загрузка и уведомления. Размер текста задан относительно пользовательской настройки; исходный размер при стандартной настройке сохранён.
- Небольшие переходы 150–220 мс через opacity/transform. Контакты анимируются только при явном добавлении, удалении и перестановке. Таймер и ввод текста не запускают повторные анимации. При reduced motion движение отключено.
- Кастомные combobox вместо видимых нативных select; поиск в списках длиннее семи вариантов. Связанная точка ищется через прежний API с debounce, пагинацией, состояниями загрузки, пустого результата, ошибки и повтора.
- Списки вынесены в body, выбирают открытие вверх/вниз, следуют за якорем при прокрутке и не обрезаются редактором. Выбор с клавиатуры, typeahead, Escape, Tab, ARIA и disabled.
- Собственный календарь с русскими подписями, выбором дня, ручной датой, часами/минутами, «Сегодня»/«Завтра», отменой и подтверждением. Сохраняется прежняя конвертация локального времени выбранного города в API.
- Собственная палитра с HEX, RGB и пресетами; неверный HEX не сохраняется молча. Кнопка/зона загрузки файла оформлена приложением, настоящее окно выбора остаётся системным.
- Меню действий и подсказки оформлены общими компонентами. Видимых checkbox/radio/switch в текущих формах нет; новые продуктовые поля не добавлялись.
- Все app-owned подтверждения используют общий диалог: удержание/возврат фокуса, Escape, отмена по фону, блокировка фоновой прокрутки, закрытие после анимации и защита от повторного подтверждения.
- Предпросмотр обновляет текст и атрибуты существующих узлов. При неизменном blob URL сохраняются настоящие DOM-узлы карточки и изображения; ошибочное изображение получает стабильный fallback.

Нативное предупреждение `beforeunload` при закрытии изменённой вкладки сохранено: браузер не допускает его замены асинхронной модалкой приложения. Окно ОС выбора файла, системные разрешения и предупреждения безопасности не подменяются.

## Найденные и устранённые дефекты

- После появления кнопок combobox фильтры могли назначить submit первой кнопке формы вместо «Применить фильтры»; назначение теперь явное.
- Повторно открываемое меню сохраняло inert и завершённую exit-анимацию. Открытие очищает это состояние.
- Список мог закрыться при автоматической прокрутке к полю в длинной форме. Теперь он пересчитывает положение, пока якорь виден.
- Позднее первоначальное чтение связанной точки могло заменить введённый поисковый запрос; текущий ввод сохраняется, Escape возвращает сохранённый выбор.
- Увеличенный текст мог расширять мобильную шапку за пределы viewport; контейнеры и навигация адаптированы.
- Календарь мог растягиваться на всю ширину поля и обрезать нижние действия; ширина отдельного popup теперь сохраняется, сторона выбирается с учётом полной высоты.
