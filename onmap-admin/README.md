# Локальная панель владельца OnMap

Самостоятельное Node.js-приложение для обзора статистики и управления партнёрскими размещениями. Не является публичным сайтом или частью mobile. Работает только на `http://127.0.0.1:4173`; Host проверяется, чтобы не допускать DNS rebinding. Localhost и CORS не заменяют проверку owner-токена на backend.

## Запуск

Node.js >= 22.11. Сначала один раз установите собственные зависимости приложения:

```sh
npm ci --prefix onmap-admin
```

Из корня репозитория:

```sh
npm --prefix onmap-admin start
```

Откройте http://127.0.0.1:4173. В форме введите HTTPS-адрес API с `/api` и токен владельца. До входа панель читает только локальную конфигурацию; к production API автоматически не подключается. В этом этапе backend на VPS не обновлялся.

Необязательная конфигурация содержит только публичный URL:

```sh
ONMAP_ADMIN_API_URL=https://api.example.invalid/api npm --prefix onmap-admin start
```

Это пример адреса, не готовый backend. `start` создаёт локальный `dist/` и запускает loopback-сервер. Никакие `.env` или токены в bundle не подставляются. Сборка копирует только frontend-исходники и vendor MapLibre; package lock зафиксирован. MapLibre нужен для выбора места на карте; используется прежний поставщик карт OpenFreeMap. Координаты карты относятся к размещению, GPS владельца не запрашивается. При недоступности карты остаётся ручной ввод широты/долготы. Карта не получает owner Authorization header.

## Как войти без SSH и Terminal

1. На Mac откройте локальную панель: http://127.0.0.1:4173.
2. В личном чате существующего бота OnMap отправьте `/admin` либо выберите **Вход в админку** в главном меню.
3. Нажмите **Получить токен на 20 минут**, скопируйте только токен из блока кода и вставьте в поле панели.
4. Укажите API `https://api.balakovo-go.ru/api` и нажмите **Войти**.

Раздел доступен только владельцам из `TELEGRAM_PARTNER_OWNER_IDS`, в личном чате с совпадающим отправителем. Модератор, которого нет в partner allowlist, доступа не получает. Владелец и флаг проверяются повторно при выдаче токена. Токен случайный, действует 20 минут; новая выдача отзывает предыдущий. Одна кнопка используется один раз, повтор update/callback не выдаёт ещё один токен. Для новой выдачи откройте раздел заново; предел — три выдачи в минуту на владельца.

В базе сохраняются только SHA-256 хеш, срок и аудит. Полный токен существует в ответе бота и в его личном Telegram-сообщении; он не записывается в DB outbox, журнал обработки updates или runtime-логи. Сообщение не удаляется автоматически: после копирования его можно удалить вручную. Токен не передаётся в ссылке, URL или конфигурации приложения. При ошибке отправки вернитесь в раздел и запросите новый токен: прежний нельзя восстановить из хеша.

Браузер хранит токен только в памяти, без localStorage/sessionStorage/cookie. Поле очищается после отправки; после перезагрузки страницы нужен повторный вход. Кнопка обновления токена не продлевает первоначальный срок, выход отзывает сессию. Токен разрешает статистику и партнёрские размещения; управление push, модерацией и инфраструктурой через этот API недоступно.

### Однократное подключение backend оператором

Нужны применённая миграция `20261028120000_owner_admin`, `OWNER_ADMIN_ENABLED=true`, точный `OWNER_ADMIN_ORIGIN=http://127.0.0.1:4173`, существующий owner allowlist и рабочая БД. Бот использует тот же poller, нового подключения нет. Defaults в примерах остаются выключенными.

Резервный операторский CLI сохраняется: `npm run owner-admin:token` в интерактивном backend-терминале с настроенным окружением. Он требует TTY и подтверждение, выводит токен только в `/dev/tty`. Для обычного входа он больше не нужен. Не присылайте токены в поддержку или чат разработки.

## Поведение

- Новая точка сохраняется как `DRAFT`, затем публикуется отдельным подтверждением. Сохранение существующей точки не активирует её. Пауза, возобновление и завершение — отдельные действия.
- Время формы относится к IANA-поясу выбранного города; компьютер может находиться в другом поясе. Будущий срок не становится текущим автоматически.
- Контакты сохраняют ID при неизменных типе и назначении, включая перестановку. Замена типа/номера/ссылки создаёт новый ID. Удалённые контакты в статистике нейтральные, без прежних значений и подписей.
- Редактирование проверяет `updatedAt`: устаревшая форма получает 409. Мутации используют UUID `Idempotency-Key`; тот же ключ с другим содержимым получает 409. Повтор после сетевого сбоя использует прежний ключ в пределах текущей страницы/сессии. После перезагрузки сначала проверьте список, если результат запроса был неизвестен.
- Изображение доступно после сохранения черновика. Используется прежний sanitizer PNG/JPEG/WebP, максимум 4 МБ, прозрачный canvas 256×256. Ошибка декодирования не удаляет старое изображение. Изображения остаются в PostgreSQL и входят в существующий DB backup.
- Баннер сохраняется выключенным, включая редактирование прежде включённого баннера. Включение требует отдельного действия. Точка и её срок не изменяются. Цвета наследуются от точки; новых цветовых полей у баннера нет. Предпросмотр не отправляет рекламную статистику.
- Статистика — суточные агрегаты UTC: 7/30 дней включают текущий день; «всё время» включает известную историю до сегодняшнего дня. Показы, открытия и клики не смешиваются. Уникальные люди/посетители не вычисляются.
- Карточка учитывается по прежнему лимиту 15 минут; баннер — после секунды реальной видимости и не чаще раза в час; контакт/нажатие баннера — не чаще раза в минуту. Просмотр админки ничего к этим метрикам не добавляет.
- Счётчик identities показывает только впервые замеченные после запуска учёта анонимные идентификаторы с датой начала. Он не оценивает историческую аудиторию и не считает людей.
- Денежные поля, пользовательские координаты, IP и push/identity-токены в отчёты не включаются. Адрес и координаты редактируемой рекламной точки являются её данными.

## Проверки

```sh
npm --prefix onmap-admin test
npm --prefix onmap-admin run typecheck
npm --prefix onmap-admin run lint
npm --prefix onmap-admin run build
```

Backend: `npm test -- --runInBand src/owner-admin/owner-admin-auth.service.spec.ts`. Сквозной набор: `npm run test:owner-admin:integration` с `OWNER_ADMIN_DISPOSABLE=1` и отдельным `OWNER_ADMIN_TEST_DATABASE_URL` на loopback-БД `onmap_admin_it…`. Набор очищает свои тестовые таблицы внутри этой disposable-БД; нельзя направлять его на рабочую БД. Имена env для тестов не являются production-настройками. Полный API и результаты локальной проверки описаны в `../backend/docs/OWNER_ADMIN_LOCAL_RU.md`.

Редизайн всех разделов и результаты браузерной проверки описаны в `REDESIGN_CHECKS.md`. Не публикуйте локальный сервер на `0.0.0.0` и не проксируйте его в интернет.

## Обновлённый интерфейс

Все разделы используют общий горизонтальный хедер. В редакторах слева расположен контекстный список, в центре — группы полей, справа — живой предпросмотр. Сохранение закреплено внизу. На узком экране список становится горизонтальным, а предпросмотр открывается отдельной кнопкой; поля и нижние действия остаются доступны.

Карточка и оба состояния баннера повторяют визуальные правила mobile `PartnerPointSheet`, `PartnerArtwork`, `MapHeader` и `partnerAppearance`: кремовая поверхность, маленькое изображение, штатная буква «П», адрес, описание, промокод с условиями, первый контакт как основное действие. Светлые акценты получают контрастный UI-цвет; исходные цвета не меняются. В редакторе точки вкладка баннера показывает только действительно связанный сохранённый баннер, если он есть. Она не составляет рекламный текст из полей точки. Предпросмотр не открывает ссылки, не копирует промокод и не отправляет статистику.

Баннер выбирает связанную точку поиском по названию; UUID сохраняется внутри формы. Один баннер на город, отдельные сохранение выключенного черновика и включение сохранены. Цвета баннера наследуются от точки. Даты формы относятся к IANA-поясу выбранного города, статистика — к суточным UTC-агрегатам за 7/30 дней или всё время. Произвольных диапазонов и графиков нет, поскольку API их не предоставляет. Таблица статистики использует только возвращённые подписи и ID контактов; исторические номера и адреса удалённых контактов не восстанавливаются.

Диалоги подтверждения и ухода из изменённой формы — собственные `<dialog>` с модальным фокусом, Escape и возвратом фокуса. При закрытии/перезагрузке самой вкладки стандарт браузера допускает только его системное предупреждение `beforeunload`; приложение не имитирует такое окно. По ответу 401 или завершении TTL данные панели и токен из памяти очищаются. Ответ 409 сохраняет форму и предлагает заново загрузить актуальную запись с подтверждением потери несохранённых полей.

Изображение выбирается после первого сохранения черновика и отправляется при сохранении формы. Поля и файл используют существующие отдельные endpoint-ы, поэтому это две операции, а не общая backend-транзакция. Если загрузка файла не удалась после сохранения полей, прежнее изображение остаётся, выбранный файл сохраняется в памяти для повтора. Ключи идемпотентности и `expectedUpdatedAt` передаются как раньше.

Для повторяемой браузерной проверки сначала запустите панель обычной командой, затем:

```sh
node onmap-admin/test/run-browser-check.mjs
```

Проверка использует Playwright CLI из установленного skill Codex; другой путь можно передать через `PLAYWRIGHT_CLI`. Она открывает отдельную сессию `onmap-redesign-qa`, перехватывает HTTPS-запросы к зарезервированному `.invalid`-домену и подставляет синтетические ответы. Настоящая backend-аутентификация не обходится: тестовые маршруты существуют только внутри этого браузера. Fixtures и сценарий находятся в `test/`, сборщик их не копирует в `dist`. Рабочий сервер, env, БД и VPS для UI-проверки не нужны. Скриншоты сохраняются в игнорируемый Git каталог `output/playwright/`.

## Контролы и доступность

Селекты, календарь, палитра, меню и подтверждения используют общие компоненты OnMap. Стрелки и Enter выбирают вариант, Escape отменяет выбор, Tab продолжает навигацию. В длинном списке доступен поиск. Календарь также поддерживает Home/End, PageUp/PageDown и ручной ввод даты/времени; применение отдельно от выбора дня. Время по-прежнему относится к IANA-поясу города.

Фирменная кнопка загрузки открывает настоящее окно ОС. Предпросмотр сохраняет DOM изображения при вводе текста. При `prefers-reduced-motion` необязательное движение отключено; увеличенный текст учитывается через относительные размеры шрифта.

Для повторной проверки только контролов: `node onmap-admin/test/run-browser-check.mjs --controls-only` (из корня проекта). Результаты, перечень файлов и ограничения проверки — в [POLISH_CHECKS.md](POLISH_CHECKS.md).
