# Редизайн локальной админки OnMap — 28 октября 2026

Работа выполнена внутри существующей `onmap-admin`. Стек сохранён: vanilla JS, Golos, локальный Node static server, существующий MapLibre. Новые зависимости не добавлены. Backend, mobile, production env, БД, миграции, VPS, Telegram и push в этом проходе не изменялись. Предыдущие незакоммиченные изменения вне админки проверены по SHA-256 относительно checkpoint.

## Запуск

Из корня проекта: `npm --prefix onmap-admin start`. При первом разворачивании исходников: `npm ci --prefix onmap-admin`. Адрес — `http://127.0.0.1:4173`, только loopback. Для подключения нужны прежние HTTPS API и короткоживущий owner-токен; настройка backend описана в README и не выполнялась на VPS.

## Что реализовано

- Экран входа, состояния подключения/ошибки/истёкшей сессии. Маскированный токен очищается из поля после отправки и хранится только в памяти API-клиента.
- Горизонтальный хедер с разделами, временем сессии, ротацией токена и выходом. Все старые ограничения HTTPS, Host, CSP и CORS сохранены.
- Обзор: глобальные накопленные показатели отдельно от фильтруемой рекламы, пояснение запуска учёта анонимных идентификаторов, раздельные рекламные метрики и пагинированная таблица контактов.
- Партнёрские точки: контекстный список, фильтры и поиск, выбор точки, создание черновика, отдельные действия статуса. Завершённая точка доступна только для просмотра.
- Группы редактора: основное, адрес/карта, контакты, промокод/условия, изображение/цвета и период. Карта поддерживает выбор и перенос маркера; ручные координаты доступны при недоступности карты. Цвет и изображение маркера обновляются из формы.
- Контакты добавляются, удаляются и переставляются с сохранением ID в DTO; окончательное решение о смене ID принимает прежний backend-домен.
- Изображение доступно после первого сохранения черновика. Файл выбран в памяти, виден в предпросмотре и отправляется при сохранении. Ошибку нельзя считать общей транзакцией: поля и файл сохраняются двумя существующими API-операциями.
- Баннер: контекстный список по городам, поиск связанной точки по названию без обязательного ввода UUID, собственные заголовок/текст/действие/срок, отдельное подтверждение сохранения выключенным и действия включения/паузы/завершения.
- Предпросмотр карточки и двух состояний баннера соответствует текущим mobile-компонентам. Маленькое изображение или «П», кремовая карточка, акценты, адрес, описание, промокод/условия, выделенный первый контакт. Поля точки и баннера не копируются автоматически друг в друга. Все действия в предпросмотре инертны.
- Кастомные подтверждения, диалог несохранённых изменений, Tab/Shift+Tab, Escape, возврат фокуса. При закрытии самой браузерной вкладки используется допустимое браузером системное предупреждение beforeunload; свой async-диалог в этом событии технически невозможен.
- Загрузка, пустые выборки, повтор после ошибки, локальная валидация полей, HTTP 400 рядом с полем, HTTP 409 с сохранением введённых данных и подтверждённой перезагрузкой, HTTP 401 с очисткой панели.
- Ключи Idempotency-Key, повтор после сети, expectedUpdatedAt и IANA-конвертация сохранены. Если запись сохранена, но её повторное чтение не удалось, предлагается проверить созданную запись вместо повторного создания.
- На узком экране контекстный список сворачивается кнопкой «Список», поля и предпросмотр переключаются, действия закреплены. На широком экране сохранена композиция макета.

## Проверки

- `npm --prefix onmap-admin test`: 17 unit-тестов, все прошли.
- `npm --prefix onmap-admin run typecheck`: прошёл, включая импортированные UI-модули.
- `npm --prefix onmap-admin run lint`: прошёл.
- `npm --prefix onmap-admin run build`: прошёл. Fixtures и browser-сценарии в `dist` отсутствуют.
- `git diff --check`: прошёл.
- Chromium / Playwright CLI, отдельная сессия `onmap-redesign-qa`: основной путь, негативные сценарии и визуальные крайние случаи прошли. Необработанных JS-ошибок — 0. HTTP 400/401/409/500 и один сетевой сбой создавались намеренно fixture-ами и отобразились в сетевой консоли как ожидаемые ошибки.
- Основной путь: вход → обзор/период → создать черновик → заполнить поля/промокод/контакт → сохранить → открыть повторно → изменить подпись → переставить контакты → статистика → поиск точки для баннера → сохранить баннер выключенным.
- Негативные случаи: 500/повтор, пустой список, отсутствующие необязательные поля, 409/сохранение формы/перезагрузка, удержание и возврат фокуса, повтор того же ключа после сетевого сбоя, серверная ошибка поля, очистка при 401, ротация и отзыв.
- Визуальные случаи: 1600×1000, 900×900 и 390×844; длинные название/описание, восемь контактов, красный/зелёный/синий/светлый акценты, широкое и вертикальное растровые изображения с contain, fallback повреждённого изображения. Горизонтального скролла всей страницы нет.

Браузерные тесты работают только с перехваченным HTTPS `.invalid` API, синтетическими данными и синтетическим стилем карты. Реальные тайлы, настоящий backend и запись в рабочую БД не проверялись. Физические устройства, Safari и Firefox этим прогоном не проверены.

Повтор браузерной проверки: сначала запустить локальную панель, затем `node onmap-admin/test/run-browser-check.mjs`. Нужен доступный Playwright CLI; путь переопределяется через `PLAYWRIGHT_CLI`. Скрипт управляет только собственной сессией `onmap-redesign-qa`.

## Ограничения фактического контракта

- Нет API динамики/произвольных дат: показываются только 7/30 дней/всё время и имеющиеся агрегаты.
- Статистика возвращает подписи и ID контактов, а не полную контактную информацию; таблица не придумывает типы, номера или ссылки. Удалённые контакты остаются нейтральными.
- Категория точки — свободное текстовое поле, поскольку справочника категорий в owner API нет.
- Список точек не содержит изображений. В нём используется штатный знак, без N+1 загрузок полной карточки ради логотипов. Изображение выбранной точки читается существующим защищённым endpoint-ом. Для логотипов всех строк в будущем нужен отдельный согласованный thumbnail-контракт; backend ради макета не расширялся.
- На город предусмотрена одна запись баннера. Интерфейс не создаёт произвольное количество баннеров.
- В текущем проходе ничего не развёрнуто, не закоммичено, не отправлено в remote и не опубликовано.
